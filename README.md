# 一儿布布冒险记（Phaser 3 迁移版）

## 运行

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
pnpm verify
```

## 功能对应表

| 原 Canvas 功能                     | Phaser 3 实现                                          |
| ---------------------------------- | ------------------------------------------------------ |
| `requestAnimationFrame` 与手工碰撞 | Arcade Physics、静态平台组与碰撞器                     |
| 自制相机坐标                       | `Camera.startFollow`、deadzone、world bounds           |
| 内嵌角色 PNG                       | `src/assets/sprites/characters.png` spritesheet 与动画 |
| 键盘/DOM 触摸按钮                  | `InputManager` 与 UIScene 多点虚拟控制                 |
| 手工状态/HUD                       | Registry 数据事件和独立 UIScene                        |

## 主要物理参数

参数集中在 `src/config/constants.ts`。`COYOTE_TIME=125ms` 为离台后跳跃宽限，`JUMP_BUFFER_TIME=135ms` 为提前按跳的缓存；`JUMP_CUT_MULTIPLIER=0.45` 使短按更低；上升和下落分别使用 `NORMAL_GRAVITY`、`FALL_GRAVITY`，下落更快。视觉精灵为约 79×88；`CharacterBody` 根据各角色所有动画帧的非透明范围计算固定矩形碰撞体，覆盖完整角色，并随精灵统一缩放。碰撞体不随动画切帧改变。

## 当前设备支持

本轮版本按 PC 同机双人 MVP 的设备范围调整为电脑浏览器游玩。手机和平板在加载 Phaser 和游戏资源前展示不兼容提示；检测结合设备 UA、UAData 与 iPad 触控特征，不以窗口宽度判断。既有触控代码保留供后续恢复移动端时使用。

单人入口与原有键位保留。主菜单点击“同机双人”或按 C，P1 按 E、P2 按 Enter 准备，两人松开准备键后进入独立的双人教学关。

| 玩家 | 移动 | 跳跃 | 互动 | 技能 |
| --- | --- | --- | --- | --- |
| P1 一二 | A / D | W | E | F 预留，无技能效果 |
| P2 布布 | ← / → | ↑ | Enter | 按住右 Shift 托举 |

Esc 暂停或恢复。布布在安全地面托举，一二跳到头顶站稳后再按 W，可到高台操作开桥机关。依次完成双开关、共同检查点与共同终点；掉落仅复活自己，桥与门保持开放。暂停和结算页提供重新挑战与返回菜单。

双人专项测试：`pnpm test:coop`，已纳入 `pnpm test` / `pnpm verify`。测试范围、关键文件、占位动画和人工验收见 [PC 同机双人合作 MVP 验收](docs/2026-10-22PC同机双人合作MVP验收.md)。

## 地图安全范围

`LevelValidator` 在开发环境根据跳速、重力和最大水平速度估算高度与距离，并对相邻平台危险跳跃给出控制台警告。主线平台间隔应保持在理论最大距离的 65%～75%（当前采用约 70%），落地区至少留一个角色宽度；较大坑洞应加入桥接平台，高台前加入过渡平台。

## 添加新关卡

1. 在 `src/levels/` 创建新关卡并复用 `LevelData`（当前已有 1-1 和 1-2）。
2. 为平台、星星、敌人和出生/终点填写数据后调用 `LevelValidator.validate`。
3. 在 `src/levels/index.ts` 的 `levels` 中注册，游戏、解锁和下一关逻辑会按顺序读取。
4. 保持主线路径满足安全范围，再为支线添加更高难度奖励。

## 星光特效与唤醒玩法 MVP

主菜单点击“星光唤醒体验关”或按 3，J/触控投掷点亮花苞、激活 8 秒跳台；唤醒三朵花后打开星门。体验关独立于正式两关存档。

设置/暂停菜单可切换画面质量与减少动态效果；编辑器新增成对的花苞/限时平台，示例地图位于 `maps/starlight-awakening-30s.json`。功能范围、降级策略和未完成的实机验收见 [星光玩法验收](docs/2026-10-19星光特效与唤醒玩法MVP.md)。

## 泡泡守护 MVP

完成基础引导后按 **K**（手机点“护盾”）开启：持续 5 秒、抵挡一次接触/敌方弹体伤害，开启起冷却 12 秒。抵挡后有 450ms 接触保护，不击退；坠落取消护盾但不退冷却，沿用原有坠落复位与受击无敌规则。暂停冻结所有技能计时，长按不会在冷却结束自动施法。两位角色、主线/自定义地图均可使用，不改动存档和地图格式。本轮不含反弹。

验收范围与未完成的真机检查见 [泡泡守护验收](docs/2026-10-19泡泡守护MVP.md)。下一项为星跃冲刺。
