> 执行方式：每次修改战斗、场景生命周期或首关数据后，在桌面键盘和移动横屏各完成一次。

## 自动检查

- [ ] `pnpm lint` 通过。
- [ ] `pnpm build` 通过（在本机常规终端或 CI 执行）。
- [ ] 浏览器控制台无未捕获异常、资源加载失败或 Phaser 物理警告。

## 开始与控制

- [ ] 选择一二和布布后都能进入首关，角色头像与游戏内动画正确。
- [ ] A/D、方向键、W/上方向键/空格、J 分别能移动、跳跃和投掷。
- [ ] 移动横屏中，摇杆、跳跃和投掷可同时使用，松开后输入立即复位。
- [ ] 暂停后角色、敌人、所有弹体与倒计时停止；恢复后继续，且不会重复发射或重复扣时。

## 战斗

- [ ] 敌人只在角色进入其配置射程并经过冷却后发射；角色离开射程后不发射。
- [ ] 敌人被踩踏或被玩家弹体命中后停止移动、攻击和碰撞，并在消失后不再触发伤害。
- [ ] 玩家弹体只伤害敌人；敌方弹体只伤害玩家；双方弹体均会在命中平台、命中目标、出界或超时后消失。
- [ ] 同一枚弹体只产生一次伤害或击杀结算。
- [ ] 连续处于多名敌人射程并持续投掷时，玩家仍可按冷却正常发射，不受敌人弹体数量影响。
- [ ] 受伤期间再次接触敌人或敌方弹体不重复扣血；无敌时间结束后可再次受伤。

## 首关流程与稳定性

- [ ] 坠落后扣除一次生命并回到当前检查点，角色可继续移动，且不会连续扣血。
- [ ] 经过检查点后坠落，回到检查点而非出生点。
- [ ] 生命耗尽、计时结束、到达终点分别只显示一次结算页。
- [ ] 从失败和胜利结算页反复“再玩一次”至少 5 次；没有叠加 HUD、倒计时、事件监听或场景报错。
- [ ] 连续游玩 10 分钟或完成 10 次重开后，无持续增长的可见弹体、角色无法操作或明显卡顿。
