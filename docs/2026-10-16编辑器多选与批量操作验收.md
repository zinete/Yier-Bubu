# 编辑器多选与批量操作 · 使用与验收

日期：2026-10-16。对应深度优化计划第 3 批 / P1。代码及自动化已完成；下方浏览器视觉、触屏与实际试玩仍需人工验收，不将 jsdom 测试视作浏览器通关验证。

## 操作方式

先选择「选择 / 拖动」工具。

| 操作 | 效果 |
| --- | --- |
| 单击未选中对象 | 只选中该对象 |
| Shift 点选对象 | 加入选区；再次 Shift 点击移除 |
| 从空白处拖框 | 选择操作/碰撞框被完整包含的对象，支持反向拖框 |
| Shift 从空白处拖框 | 将框内对象追加到现有选区，自动去重 |
| 拖动已经选中的任一对象 | 整个选区一起移动，不取消其他选择 |
| 方向键 / Shift＋方向键 | 整体移动 16px / 64px；右侧也提供四向按钮 |
| 画布内 Ctrl/⌘＋A | 全选玩法对象，不选背景/前景场景图层 |
| Ctrl/⌘＋C、V、D | 批量复制、粘贴、直接创建副本 |
| Delete | 批量删除可删除对象 |
| Ctrl/⌘＋Z / Ctrl/⌘＋Shift＋Z、Ctrl/⌘＋Y | 一次撤销 / 重做整批操作 |
| 定位对象 | 以整个选区边界中心定位视口 |
| Alt 点选 | 退回单选，编辑具体属性、宽高或单对象尺寸手柄 |
| Esc | 拖动/框选中取消本次交互；非交互时取消选择并退出放置工具 |

框选采用「完全包含」，小框擦过地面不选中整段地面。只能从空白处开始框选；覆盖密集处可用 Shift 点选或全选。框选拖动超过 3 个屏幕像素才启动；空白轻点清空选区。

输入框保留原生的复制、粘贴、删除和全选快捷键。表单存在待应用修改时不能切换选择或批量修改，需先应用或取消表单。背景图层仍走原有独立图层面板，不包含在玩法多选中。

## 数据与安全规则

- 出生点、检查点、终点仍为唯一标记，可以单独或整体移动，不能复制、删除；混合选区复制/删除会跳过它们并提示。
- 整体移动按 16px 网格吸附，以选区整体约束地图边界，不逐个挤压对象位置。旧地图中未对齐的位置和尺寸首次操作会各自规范到网格，可能产生小幅相对调整；后续网格对象保持相对布局。
- 选区无法完整放入地图时拒绝移动/粘贴，不丢失选区成员。碰边且没有任何数据变化的批量移动不新增撤销记录。
- 敌人巡逻边界随整体位移平移，到地图边缘才截断；攻击设置、装饰前后景、平台类型与外观保留。每个复制平台使用新 ID。
- 粘贴从复制快照逐次偏移 `32×16px`；若右下无法偏移，尝试向左上偏移。两向都没有空间则拒绝，不生成完全隐藏的副本。反复粘贴靠近边缘时可能落在同一受限偏移处，后续可手动移动。
- 粘贴先检查整批素材引用、坐标、对象数量限制，再验证候选地图；任一失败不写入任何副本，不增加历史或粘贴次数。数量上限仍为平台 200、星星 300、敌人 40、装饰 200。
- 复制是独立快照，之后修改原对象不污染剪贴板。剪贴板只在工坊内部存在，不读取系统剪贴板，不支持跨地图粘贴。
- 框选、增减选区、定位与缩放不改变地图、不标记未保存、不增加历史。多选面板不提供批量宽高/外观编辑，以免误改。
- 拖动结束才写一次历史；Esc、pointercancel、失焦、场景销毁会回滚未结束的拖动。异步导入/上传落地前也取消未完成交互，避免旧索引修改新地图。

## 浏览器手工验收清单（待执行）

1. 导入自己的长地图，在 50% / 100% / 200% 下正反框选，滚动后继续操作；确认橙色选框、选区外框、敌人巡逻线和右侧统计匹配。
2. 把多种对象拖到左、右、上、下边界，确认相对间距不被压缩，角色试玩碰撞仍与编辑边界一致。
3. Shift 选择整段台阶和星星，复制多次、删除、撤销、重做；进入试玩确认星星、敌人攻击和站立行为。
4. 混入出生点、检查点、终点，分别复制和删除，确认标记保留；仅选标记时按钮禁用，仍能整体移动。
5. 拖动过程中按 Esc、切到其他应用；重新聚焦确认原位置和保存状态正确。框选后保存、刷新、重新进入，确认数据正确、选择状态不持久化。
6. 验收触屏/触控笔的捕获与取消。MVP 没有自动边缘滚动、触屏多选工具、跨层框选、组合/解组、对象对齐分布；这些不在本批交付内。
