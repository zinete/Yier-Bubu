# 《一二布布冒险记》四主题分层背景系统

## 旧实现分析

旧背景由 `SceneBackdrop` 和 `ForestArt` 在运行时创建大量圆形、椭圆、矩形与半透明 Graphics。优点是无素材依赖，但存在三个问题：四个主题主要依赖配色区分；长关卡需要生成大量节点；编辑器预览与实际游玩容易出现表现差异。

## 当前组件架构

- `ThemeBackground.ts`：背景主题配置、四层视差参数、纹理预加载、视口复用池和编辑器 SVG 预览。
- `assets/backgrounds/<theme>/`：每个主题独立维护 `sky.svg`、`far.svg`、`mid.svg`、`front.svg`。
- `ForestArt.ts`：优先挂载素材背景；素材加载失败时才回退到旧几何背景，不影响关卡启动。
- `EditorScene.ts`：地图工坊使用与游戏运行时相同的主题素材和视差参数。
- `PreloadScene.ts`：统一加载 16 个可复用 SVG 纹理；背景纹理不属于关键碰撞资源。

## 图层规范

| 图层 | 默认滚动系数 | 深度 | 内容职责 |
| --- | ---: | ---: | --- |
| 天空 sky | 0 | -30 | 天色、太阳、月亮、云、星星 |
| 远景 far | 0.12 | -27 | 山脉、远丘、远处地貌 |
| 中景 mid | 0.32 | -23 | 树木、雪松、仙人掌、夜光植物 |
| 前景 front | 0.62 | -19 | 草丛、雪堆、沙砾、近景植物 |

所有主题层均位于玩法对象和用户前景图层之后，不创建物理体，也不参与碰撞。

## 四主题差异

- 绘本森林：圆润阔叶树、柔和丘陵、蕨类和花草。
- 雪地：尖峰雪山、覆雪松树、冰晶与雪堆。
- 沙漠：沙丘、台地、仙人掌、岩石和耐旱灌木。
- 星空夜晚：月亮和星座、夜色山丘、发光蘑菇与夜光植物。

## 长地图与性能

运行时每层只维护覆盖当前镜头所需的少量 Phaser Image。镜头跨过一个素材块时才重新排列节点；静止或同一块内移动不会重新绘制 SVG。素材块交替镜像，实现横向连续衔接，节点数不随地图长度增长。

编辑器使用 SVG pattern 预览，同样不会按百万像素地图长度复制大量 DOM 节点。

## 后续替换 AI 美术资源

保持文件名与 1920×540 画布不变，即可直接替换对应 SVG；也可以将 `ThemeBackground.ts` 的素材导入改成同尺寸透明 PNG。建议：

1. `sky` 必须铺满画布且左右色彩连续。
2. `far/mid/front` 保持透明底，并在左右边缘预留可衔接区域。
3. 关键轮廓避开玩家常用高度，防止降低角色、机关和平台辨识度。
4. 不在背景素材中加入碰撞语义；碰撞仍只由地图对象定义。

## 兼容性

地图 JSON 结构、主题字段、场景种子、自定义背景和用户图层均保持兼容。旧几何背景保留为资源失败时的降级方案，因此本次升级不要求重做已有地图。
