# 分层场景编辑 MVP · 使用与验收

日期：2026-10-16。当前迭代在原 SVG 编辑器和 Phaser 试玩上增加独立视觉图层，不更换引擎、不改变关卡碰撞。

## 快速查看效果

1. 进入「地图工坊」，左上角新增「场景图层」面板。
2. 点击「绘本森林预设」生成天空、远山、树群和前景枝叶；有旧图层时会确认替换，原来的平台、敌人、星星、出生点均不改变。
3. 点击图层名称，在右侧「图层属性」中实时修改素材、分区、铺设、X/Y、单幅宽高、视差、透明度。素材下拉包含已有上传图片。
4. 横向滚动画布，或在原「场景设置」点击「演示横向视差」。新图层的视差独立，原基础背景视差只控制基础背景。
5. 点击「试玩」检查画面。保存草稿或导出 JSON 保留编辑结果。

也可直接导入 `maps/starlight-relay-layered-60s.json`。它沿用原 `starlight-relay-60s.json` 的完整玩法数据，只增加四个背景/前景图层，不覆盖原文件。

`docs/scene-layers-preview.png` 为共享 SVG 绘制函数生成的离线合成预览，不是浏览器截图或实机通关证明。

## 已实现

- 最多 16 个独立视觉图层；新增、复制、删除、拖动列表排序，以及「向后移/向前移」按钮。
- 分为背景和前景两个分区，各自内部按列表从后向前绘制。玩法层位于二者之间，跨分区请修改属性，不通过排序混入玩法层。
- 每层独立的素材、X/Y、单幅宽高、透明度、水平视差、单幅图片/横向平铺。
- 列表显隐与锁定；锁定后不能修改属性、删除、拖动排序，但可以显隐、解锁或复制为新的未锁定图层。
- 所有图层均无碰撞，不会因隐藏/锁定背景改变平台和敌人行为。
- 图层选择通过列表完成，画布不拦截玩法对象的选择和拖动。背景位置由右侧参数调整。
- 默认场景素材按钮会新增独立图层，不会误切换成碰撞对象放置工具。
- 连续输入合并成一次撤销；修改后恢复原值不产生空记录；支持原有撤销/重做和保存/导出/导入。
- 图层面板中的 Delete 删除当前图层，Ctrl+D 复制图层；输入框仍保留系统文字编辑快捷键。对象 Ctrl+C/V 仍在画布中使用。
- 「基础背景」可保留原主题图形，或只保留渐变天空。森林预设使用后者，避免叠加旧椭圆树；分层地图试玩不再注入编辑器里不存在的固定路牌和章节文字。
- 预设包含四张新的绘本 PNG；图层按完整图片（包括透明边缘）定位，不使用平台站立线裁切规则。

素材由内置 imagegen 生成并保存到 `src/assets/editor/scene-{sky,mountains,trees,foliage}.png`；完整生成提示词和路径见 [素材生成记录](2026-10-16森林分层素材生成记录.md)。

## 数据和渲染约定

地图仍使用 version 1，新增可选的 `scene.baseMode` 与 `scene.layers`。没有这些字段的旧地图仍按原方式显示，不自动替换视觉效果。新版字段只承诺由当前及后续兼容版本读取，旧版应用重新导出可能丢弃它不认识的字段。

每层保存稳定 id、name、assetId、group、mode、x/y、width/height、parallax、opacity、visible、locked。解析器白名单校验，拒绝重复 id、缺失素材、非法链接和非有限数值；外部地图不执行脚本。

- `mode=image`：宽高是单幅显示尺寸，不自动拉伸至整张地图。
- `mode=repeat`：宽度是一个平铺周期，高度是背景条高度，仅横向重复。任意普通图片不一定无缝，建议上传有衔接设计或边缘透明的素材。
- `parallax=0` 固定，`parallax=1` 与世界同步，0～1 之间模拟远景。MVP 不支持纵向独立视差和大于 1 的速度。
- 单幅宽度 16～16384、高度 16～4096，X/Y 范围 ±1000000；这是单块素材和数值安全边界，不是地图宽度上限。
- 编辑器用 SVG pattern，试玩用视口大小的 TileSprite，不为长地图生成无数背景副本。两者共享显示尺寸和相位公式，试玩适配相机缩放，并在退出时移除监听。
- 试玩仅加载地图引用的场景素材，旧地图不额外加载四张新背景。内置素材通过稳定编号引用，导出文件无需内嵌这四张大图。
- 上传素材沿用当前限制：最多 20 张、缩放到最长边 512px、每张编码不超过 350KB、总量 2MB；地图 JSON 导入仍为 3MB。高分辨率自定义背景素材通道留待下一轮，暂未放大上传预算。

## 验收清单

以下自动化已覆盖；真实浏览器交互与实机画面仍需人工复核：

- [x] 四个预设图层以及内置素材编号可解析，示范文件可导入。
- [x] 新字段 JSON 往返稳定；旧地图不强制新增图层；玩法数据保持不变。
- [x] 拒绝超过 16 层、重复/非法编号、缺失素材、错误分区、错误铺设方式、无效显示状态、非法尺寸/视差/透明度。
- [x] 隐藏层不创建运行时图形；锁定层不能修改/删除/排序；复制生成新编号。
- [x] 单次连续修改只记录一次撤销；撤销/重做恢复图层设置。
- [x] 图层实时输入不重建玩法对象或整个属性表单；无效输入保留上次有效模型。
- [x] 相机 X=0/300/50000、缩放 0.5/1/1.75/2 下的平铺相位与 SVG 数学一致；销毁后移除监听。
- [x] 地图从 1920 加宽到 1000000，不增加背景 SVG 节点数量。
- [x] GameScene 的真实背景创建入口已连接图层适配器。
- [x] 修复退出场景时 `Cannot read properties of undefined (reading 'off')`：Phaser 相机管理器先清空主相机，图层改为保存注册时的相机/事件实例并用原实例解绑；退出后的排队回调停止更新。回归使用当前 Phaser 的真实 `CameraManager.shutdown` 方法重现原报错，并验证连续 8 次挂载/退出无残留监听。原测试未模拟引擎先销毁相机的顺序，已补齐。
- [ ] 浏览器点击预设、列表拖动排序、滑动/输入、保存刷新、导出重新导入的端到端操作。
- [ ] 在宽屏/窄屏试玩，检查画面铺设、性能和视觉遮挡，完成关卡通关验收。

检查命令：`pnpm test`、`pnpm lint`、`pnpm build`。原有构建包体大于 500KB 的提示仍存在，不是本轮构建失败。

可选离线视觉检查：安装/使用可用的 sharp Node 包后运行 `node tests/render-layered-scene.mjs`。如果 sharp 不在项目模块路径中，可用 `SCENE_PREVIEW_MODULES` 指向外部 node_modules；不需要改项目依赖。它检查 alpha、读取实际图片几何，调用共享图层/平台 SVG 函数并生成预览。

## 后续迭代顺序

1. 场景区域：同一关卡的草甸、深林、遗迹分区与过渡。
2. 图层分组、多选、组合预设、装饰笔刷；按需增加画布直接定位背景的编辑模式。
3. 落叶、萤火虫、薄雾等动态氛围，配合低动态效果设置和性能预算。
4. 高分辨率背景上传、素材包清单/压缩、按区域加载，继续保留分享文件的可移植性。
