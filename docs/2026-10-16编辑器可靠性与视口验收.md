# 编辑器可靠性 P0 与基础视口 P1 · 使用及验收

日期：2026-10-16。沿用当前地图 version 1 与现有碰撞/素材系统；先交付可靠保存与基础导航，不包含多选和完整模型重构。

## P0：保存与恢复

- 顶栏显示「新地图」「已保存」「未保存」「已自动备份」「保存失败」等状态，不再把失败显示为成功。
- 手动保存失败时，保留地图内存和上次成功记录，阻止进入试玩或返回主页；可以导出 JSON 救援。
- 应用后的模型变更空闲约 1 秒写入独立自动恢复记录；失焦、页面隐藏/关闭、编辑器退出也尝试备份。拖动中的临时模型不自动写入。
- 刷新进入工坊时，自动恢复与当前手动版本匹配的未提交备份，显示恢复提醒；过期备份不覆盖较新的手动保存。
- 撤销回手动保存状态时清理旧备份，避免刷新后复活已经撤销的内容。清理失败会提示手动保存确认版本。
- 新建、导入前检查未保存模型。已确认替换可用撤销找回；不要把刷新后仍能撤销作为保证。
- 浏览器离开提示覆盖未保存模型、未应用表单和持久化错误；系统是否显示确认框取决于浏览器和用户激活状态，不能保证异常进程退出前一定执行。
- 尽力检测其他页面对主草稿或自动备份的变化，阻止已观察到的覆盖冲突，不自动把其他页面内容写入当前模型。它不是事务性跨页锁，也不是协同编辑系统。
- 文件异步导入/图片处理检查发起编辑器根节点，旧场景完成的任务不能写入后来重开的编辑器。
- 损坏记录不会被标记为「已保存」；试玩返回时若存储读取失效，保留已有内存地图，不用空地图覆盖。

### 草稿兼容与备份边界

手动草稿仍在 `yierBubuEditorDraftV1` 键，但新写入数据使用版本化 `editor-draft` 包装，包含时间、修订随机量和地图。新代码兼容读取旧版裸地图。自动恢复使用独立 `yierBubuEditorDraftV1:recovery` 键，并记录基于哪个手动版本编辑。

导出的地图仍是裸 `CustomMap` JSON，不包含存储包装，分享和导入格式不变。未完成关卡现在也能导出为 `star-map-draft.json` 并重新导入编辑；只有试玩要求出生点、检查点、平台、终点通过完整校验。

自动备份只包含已经应用的地图内容。存储仍为 localStorage，空间不足、浏览器权限或数据被清理时可能失败；状态会提示，但不替代导出文件。后续计划把地图与素材 Blob 分开存入 IndexedDB，当前没有扩大上传额度或承诺大图草稿一定能自动备份。

## P0：表单事务保护

- 对象、地图、平台材质表单继续使用「应用」交互。编辑后显示待提交提示。
- 不能带着未应用表单静默切换对象、换工具、保存、导出或离开；可点击「应用全部待提交设置」或「取消待提交设置」。
- 多张表单一起应用时，任意一项无效则全部不提交，保留输入，模型、撤销栈和笔刷不变。
- 取消待提交设置会确认；已应用的地图不受影响。
- 缩小地图宽度不能截断已有对象；无效敌人速度、空数字、非正尺寸、非法材质等不会留下半成功状态。
- 背景和图层实时设置沿用实时模型预览，不要求再点对象属性的应用按钮。背景编辑与对象表单不是同一种提交交互。
- 待提交表单存在时仍可缩放、定位和使用中键平移；不会因此重建或丢失输入。

## P1：基础画布导航

- 顶栏 `−/＋` 缩放；`100%` 恢复世界单位与 CSS 像素 1:1 的显示比例。
- 画布内 Ctrl/⌘＋滚轮以鼠标位置缩放；普通滚轮不被拦截。
- 缩放范围 5%～300%。「适应视口」考虑当前画布可用宽高；超长地图达到最小缩放后可能仍需横向浏览，会明确提示。
- 「定位对象」定位画布选中的玩法对象；「回到出生点」定位出生标记。背景图层目前仍由列表选择、参数定位，不借此按钮强行改变背景视差。
- 视图变动不写入地图、不产生撤销记录、不改变保存状态。碰撞吸附和方向键移动仍使用 16 世界单位。
- 指针锚点会受浏览器滚动边界限制；例如整个画布比视口小时，不可能为保持任意鼠标锚点而滚动到负坐标。

检查命令：`pnpm test`、`pnpm lint`、`pnpm build`。包体大于 500KB 的原提示仍存在。

## 浏览器人工验收（待执行）

1. 修改地图标题但不应用，尝试保存/换对象：应提醒，不丢输入；应用全部后再保存。
2. 放置平台并等待备份状态，刷新、重新进工坊：应恢复并提醒；保存后再次刷新应显示已保存。
3. 编辑、等待备份、撤销回保存版本，再刷新：被撤销的内容不应回来。
4. 模拟存储空间不足：保存失败不得进入试玩/主页；已应用地图仍能导出，包括未完成草稿。
5. 连续执行「编辑 → 保存 → 导出 → 导入 → 试玩 → 返回编辑」至少 10 次，检查控制台、键盘响应、相机和纹理资源。
6. 在 50%、100%、200% 下放置/拖动/调整平台和星星，检查碰撞辅助线及网格，不应出现比例引起的漂移。
7. 对长地图选择远处对象后定位，再回出生点；缩放应保持合理视口位置，不滚到空白区域。
8. 两个页面编辑同一草稿：出现变化时应提示导出/刷新，不能静默将另一个页面内容覆盖当前模型。
