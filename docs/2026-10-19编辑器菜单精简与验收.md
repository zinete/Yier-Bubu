# 编辑器菜单精简 · 使用与验收

日期：2026-10-19。解决左侧菜单过长、常用工具随滚动消失、对象和图层属性混排的问题。此批仅调整交互与布局，不改变地图数据格式、碰撞、历史、素材额度或保存方式。

## 新入口

常用「选择、平台、星星、敌人」始终在左上方，独立于内容滚动区。下面只有四个分类，同时只显示一个分类；每个分类保留自己的滚动位置。

| 分类 | 内容 |
| --- | --- |
| 放置（默认） | 出生点、检查点、终点；进入素材的快捷入口；可展开的操作帮助 |
| 素材 | 默认装饰、上传图片、素材用途；高级项内的平台材质校准 |
| 场景 | 主题、图层列表、新增图层、森林预设；可展开的背景素材与基础背景高级设置 |
| 地图 | 标题、宽度、限时与应用设置；新建地图收进折叠项 |

点击对象时右侧显示对象属性；点击图层时切换为图层属性，二者不再同时纵向堆叠。复制、粘贴、删除保留；全选、取消选择和直接创建副本收进「更多选择操作」，原快捷键不变。

## 精简内容

- 不再重复列出平台、星星、敌人和路标的默认素材卡片，这些已有固定工具；对象外观下拉菜单仍可使用这些素材。
- 场景专用素材移入「场景 → 添加背景素材」，不会夹在装饰列表里。
- 移除「演示横向视差」和「保存场景设置」的界面按钮。空格拖动/横向滚动用于检查视差，保存统一使用顶部「保存草稿」。
- 基础背景视差只显示一个滑块与当前数值，取消重复的可见数字输入框。
- 材质站立线/收边比例等低频项默认折叠；重置跳台尺寸只在平台工具激活时显示；素材用途只在已选择可放置素材时显示。
- 删除重复长篇说明；完整常用快捷键集中在「放置 → 操作帮助」。现有地图、素材和高级配置不会因此删除或重置。

## 操作保护

切换分类本身不修改地图、不新增撤销、不改变当前放置工具。存在未应用的对象/地图/材质表单时，切换会提醒，先用顶部提示条应用全部或取消，避免把未提交输入藏起来。单纯切换不会重建表单，折叠项展开状态也保留。

分类标签支持左右方向键和 Home/End，使用标准 tab/tabpanel 语义与单一 Tab 焦点；分类导航不会触发对象微移。真实浏览器中的焦点和触屏体验仍需人工验收。

普通桌面高度下常用工具、分类切换和默认标记无需浏览整张长菜单。上传大量素材、多图层、展开高级项或窗口很矮时，当前分类内部仍可局部滚动；不以缩小所有文字或删除必要能力换取绝对无滚动。

## 自动化验证

扩展真实 EditorScene DOM 工作流测试，检查默认只有一个分类可见、工具区独立于滚动区、CSS 溢出与固定区属性、分类选择状态与焦点、保留滚动位置、界面切换不改数据和历史、上下文属性切换、默认素材去重、场景素材归类、低频项默认折叠、待提交保护，以及视差单控件仍正确合并撤销。

已通过 `pnpm test`（现有 14 组脚本，含新增菜单用例）、`pnpm lint`、`pnpm build`。构建仍有原有的大 chunk 提醒。jsdom 不提供真实像素布局、Canvas/WebGL 渲染或触屏验证，不能把这些自动化结果标为浏览器截图验收。

## 浏览器验收（待执行）

1. 保存草稿后刷新进入工坊，默认看到常用工具和「放置」，不再先滚过图层及大量说明。
2. 桌面普通高度及窄窗口下切换四类，确认文字/按钮未截断、当前分类可局部滚动、工具与分类标签始终可达。
3. 上传多张素材、添加多个图层后滚动内容，固定工具不随内容滚走；切换返回保留浏览位置。
4. 点击图层后编辑，再点画布对象，右侧属性只显示对应内容；复制、删除、撤销、保存与试玩正常。
5. 修改表单但不应用时切换分类，确认提示和输入保留；应用或取消后可继续。
6. 展开高级材质校准，修改并应用；调整背景滑块、撤销/重做、保存再刷新，确认原能力和数据未丢失。
