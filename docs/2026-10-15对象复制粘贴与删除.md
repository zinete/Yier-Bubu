# 对象复制粘贴与删除

## 操作

1. 按 Esc 或选择「选择 / 拖动」，点击对象；也可按 Alt 点击快速选择。橙色框表示当前选择。
2. Ctrl+C 复制当前对象快照，Ctrl+V 创建副本并自动选中它。连续粘贴逐次向右下偏移两格/一格；地图右下角无法偏移时尝试左上方向。
3. Delete 删除选中对象；Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做。删除后仍可继续粘贴之前复制的对象。
4. 右侧提供复制、粘贴、快速创建副本与删除按钮。Ctrl+D 保留为快速副本，不覆盖 Ctrl+C 的剪贴板。
5. macOS 对应支持 Command+C/V/Z。编辑文字、下拉选项、富文本时，不接管这些系统快捷键。拖拽过程中先松开鼠标再操作，避免对象数组与拖拽索引冲突。

## 数据规则

- 平台、星星、敌人和图片装饰支持复制。出生点、检查点、终点必须保留单例，只能移动，不可复制/删除。
- 复制不会修改原对象或创建撤销记录；粘贴为深拷贝，保留外观、尺寸、图层、是否可站立、敌人速度和攻击配置。敌人巡逻范围随副本的实际水平位移移动并夹在地图边界内。
- 平台副本获得新编号。粘贴继续使用 16px 网格吸附和对象数量上限，尺寸/位置受地图边界约束；没有空间时副本仍可能与其他对象重叠，可拖动重新安排。
- 复制的是素材引用，不会给每个副本重复嵌入一份图片；平台材质仍使用地图中的共享设置。素材不存在时拒绝粘贴。
- 内部剪贴板不占用系统剪贴板、不弹系统读取权限。只在当前工坊内使用，刷新/重新进入、新建或导入地图时清空。暂不支持多选和跨地图粘贴。

## 验收

- [ ] 从输入框切换到画布点击选中对象，按 Delete 正常删除，Ctrl+Z 恢复。
- [ ] 平台、星星、敌人、装饰分别 Ctrl+C/V，副本选中且保留属性；多次粘贴不影响原对象。
- [ ] 复制后修改或删除原对象，继续粘贴仍使用复制时快照。
- [ ] 在标题、坐标和场景输入框内复制/粘贴/删除文字，不改变地图对象。
- [ ] 画布边缘、对象数量达到上限、没有选中对象、空剪贴板时有合理反馈；失败不增加撤销记录。
- [ ] 唯一标记不能删除或复制；Ctrl+D 不覆盖已有剪贴板。
