# 模块化平台材质与站立线校准

## 本轮完成

- 默认苔藓平台不再整图随地图宽度拉伸，改为左收边、中段交替镜像重复、右收边。中段使用奇数段，使接缝两侧对应原图同一边界；长度变化通过调整段数适配。每段有半像素绘制冗余，减少缩放时的细缝。
- 内置素材显式标定站立线为原图第 286 行（原图高度 724，约 39.5%），不再用自动 alpha 阈值决定该素材的站立面。角色碰撞顶部、编辑器站立线、放置预览和试玩绘制共享坐标。
- 顶部新增「碰撞辅助线」，默认隐藏。开启后绿线是站立面，浅绿色矩形是物理范围；该开关不影响玩法，也不写入地图文件。
- 左侧新增「平台材质」：可选择素材，配置重复/拉伸模式、站立线百分比、左右收边百分比。配置只作用于使用该素材的可站立对象，不改变普通装饰。默认平台和开启碰撞的图片装饰均支持。
- 调整平台尺寸时，仅重绘选中平台的拼片，而不是把旧预览整体拉伸或重绘整个地图。上传的 base64 图片在平台 SVG 内只定义一次；游戏复用同一材质的裁切纹理帧。
- 材质配置支持撤销、草稿保存、JSON 导入导出，兼容没有材质字段的旧地图。

## 使用方式

1. 刷新游戏，进入地图工坊。已有草稿自动采用新的默认苔藓材质，无需删除重建。
2. 点击平台或默认苔藓素材，连续放置；按 Esc 切回选择，拖右下角调整宽度。观察草台两端保持尺寸，中间增加拼片。
3. 点击顶部「碰撞辅助线」，检查站立面。平台属性的 Y 坐标表示站立面，高度表示站立面以下的厚度，不包含伸到上方的花叶。
4. 上传自定义平台图片后，在「平台材质」选中该图片；选择重复模式，设置站立线和收边，点击「应用材质」。上传图片默认保留旧拉伸模式，避免擅自改变旧地图外观。
5. 站立线百分比以完整原图（含透明留白）的高度为基准。例如原图高 200px，脚应站在第 60 行，填写 30%。左右收边以去透明留白后的内容宽度为基准。
6. 修改一份材质会更新地图中所有引用它的平台；点击「恢复默认材质」可清除当前覆盖。点击「保存草稿」或导出地图保留设置。

## 验收清单

- [ ] 同厚度的平台宽度分别改为 160、320、960、1920px，确认两端不会随宽度无限放大。
- [ ] 地图宽度改为 9600px，放置长地面，确认通过增加中段适配，而不是整张草图拉长。
- [ ] 开关辅助线，确认只影响编辑显示，试玩中没有虚线。
- [ ] 跳到平台上，检查脚底与主要草地表面贴合；从下方起跳仍可穿过浮台、落下可站立。
- [ ] 自定义图片设置不同站立线，确认编辑器、幽灵预览、拖动尺寸和试玩一致。
- [ ] 普通花丛、角色、星星等非平台对象不受材质参数影响。
- [ ] 材质修改后撤销/重做、保存后刷新、导出后重新导入，确认配置保留。
- [ ] 旧地图可直接导入试玩；错误素材引用、非法模式、越界比例被拒绝。

## 自动检查与边界

`pnpm test` 包含地图往返、参数白名单、16～9600px 宽度与多种厚度的精确覆盖、接缝源坐标连续、站立面与底部一致、极窄平台、运行时 GameScene 调用与 Phaser 真实纹理帧检查。`pnpm lint`、`pnpm build` 用于静态检查与构建。

`platform-material-preview.png` 是从同一拼片计算离线绘制的尺寸回归图，不是浏览器试玩截图。本轮没有完成浏览器端的实际跳跃和交互复验，以上人工验收项需实际试玩确认。

Windows 下可在项目根目录运行 `./tests/render-platform-preview.ps1` 重新生成离线回归图。

这是对现有完整素材的模块化适配，不是完整 Tilemap/Terrain 系统。中段采用镜像连接，可能看出对称图案；极短平台的收边和中段仍需压缩，段数切换时中段会做适量宽度适配。花叶允许伸出平直站立面，不采用逐像素草叶碰撞。

暂不包含森林/雪地之间的分区过渡、地形画笔、斜坡碰撞或长地图流式加载。后续可在此材质配置上接入专门制作的无缝瓦片，而不再依赖完整平台插画。
