# 2026-10-23 稳定性与性能优化验收

本批在 PC 同机双人 MVP 基础上，先修可复现的玩法与资源错误，再处理编辑器和长地图性能，最后补齐双人设置入口。保留单人入口、地图 JSON 格式、跳跃速度、重力、加速度、125ms 离台宽限与 135ms 跳跃缓冲。未自动提交代码或部署。

## 已完成

| 优先级 | 问题与调整 | 验收结果 |
| --- | --- | --- |
| P1 | Arcade 在无物理步进的渲染帧仍保留着地标记；改为结合上升速度判断着地，跳跃后彻底消费缓冲与宽限 | 真实 Arcade CPU 物理，60/90/120/144/240Hz、不同步进相位下两角色均无法借旧标记二次起跳；正常落地、宽限与缓冲保留 |
| P1 | 自定义玩法素材下载/解码/像素测量失败时，不再进入隐形平台关卡 | 显示失败清单、重试、返回工坊；只重试失败资源，装饰失败可降级；退出清理回调与纹理 |
| P1 | 每个对象重复内嵌整张上传图片 | 编辑画布根部共享图片定义，普通对象、装饰、平台、背景、图层和放置预览统一引用；拖动缩放不复制原图 |
| P2 | 缩小窗口第一帧镜头缩放过大，两人被裁切 | 按新视口基准换算并立即限制 zoom；距离缩放继续平滑；减少动态效果使用固定宽视野 |
| P2 | 按住 Space/Enter 进入结算页后自动重复确认 | Space/Enter/R/H 忽略 repeat，新的物理按键仍可确认；移除旧场景监听 |
| P2 | 超长地图一次创建整图背景图元和平台图片 | 主题按镜头附近分块重绘；平台可见拼片直接按索引计算并复用 Image 池；休眠/唤醒跳台保持显示状态；旧版平铺背景也改用视口大小 |
| P2 | 编辑器长平台生成随长度增长的 SVG 节点 | 两端收边 + 正反交替中段 pattern，保留碰撞基线、厚度、接缝采样；节点数量不随平台长度增长 |
| P2 | 素材几何缓存和异步请求跨地图累积 | 最近使用缓存限 64 项 / 4Mi 字符，取消无用请求；编辑器只测量使用中素材与画笔，预览卡延迟加载 |
| P2 | PC 首屏下载未使用的触摸按钮 | 普通 PC 从 24 项位图降至 21 项；摇杆/跳跃/投掷仍保留供触控主设备路径使用 |
| P2 | 双人缺少设置/反馈入口 | 暂停页增加声音开关及音量、特效设置与反馈；反馈识别双人关、阶段和检查点，关闭面板不自动恢复玩法 |

## 自动验证

`pnpm verify`：ESLint、30 个测试脚本、TypeScript、Vite 生产构建、dist 校验通过。

新增 `pnpm test:stability` 覆盖高刷新率跳跃、结算重复输入、素材错误恢复、几何缓存释放、长地图绘制和双人设置。已有单人伤害/复活/结算、双人教学全流程、托举/检查点/单人掉落、编辑器历史/框选/复制/场景预览等回归继续通过。

| 测量场景 | 结果 | 测量边界 |
| --- | --- | --- |
| 一张约 320K 字符图片，300 个星星 + 平台/装饰/背景/图层/预览 | SVG 440,804 字符，原图出现一次 | DOM 序列化数据量；此前仅 300 个星星约 96,286,160 字符；并非浏览器堆内存测量 |
| 1920 / 100000 / 1000000px 地图，同样首屏视口 | 主题与地面首屏绘制计数均为 218 | 绘图调用计数，不是 GPU 帧率 |
| 百万像素平台，960px 视口，32px 厚度，持续移动镜头 | 池内少于 12 张平台 Image | 测试适配器验证创建数、复用与清理；物理平台长度未裁短 |
| 极长平台的编辑 SVG | 固定数量 pattern / use 节点，字符串小于 2500 字符（不含原图） | 验证数据结构，不代表任意尺寸都在浏览器硬件能力内 |
| 真实平台 PNG 离线栅格比较 | 平铺与旧逐片画法平均通道差 0.00–3.15 / 255 | 1920/10000px、缩放 0.75/1/1.5；共享图片与收边可见，检查合成预览正常 |

离线栅格比较命令（需要 sharp；不是项目安装依赖）：

```powershell
# SCENE_PREVIEW_MODULES 可指向已安装 sharp 的 node_modules 目录
node tests/platform-svg-visual.test.mjs --preview
```

输出 [平台拼接离线预览](2026-10-23-platform-render-preview.png)。百万像素的 SVG 在离线栅格器中遇到尺寸限制，因此栅格对比选用 10000px；百万像素部分验证的是可见区算法与创建数量，不声称完成该尺寸的浏览器实玩。

构建仍提示 Phaser 所在 GameApp 包超过 500KB；本批未通过调高警告阈值掩盖它。当前全部构建资源约 20.18MiB，不等于首屏传输量。菜单大图压缩与更细的资源分批加载仍属后续工作。

## 人工验收与后续顺序

以下未宣称自动验证完成：

1. 高刷新率真实浏览器、不同 PC 宽高比和全屏切换；观察角色、HUD、平台收边与视差是否稳定。
2. 同一键盘双人多键冲突；暂停、切标签、调整音量、打开/关闭反馈后再次操作。
3. 断网加载自定义平台/终点图，恢复网络后重试；坏图片替换；离开错误页再进工坊。
4. 长地图浏览器性能记录：首帧、帧率、堆内存、低配置 GPU；可见图元减少并不消除大量物理对象的成本。
5. 至少 20 分钟游玩及 10 次重开/返回菜单实机检查，双人完整通关和音频听感。

后续开发顺序：菜单及默认大图的尺寸/编码优化和弱网体验 → 独立正式双人合作关与难度打磨 → 布布下蹲/托起/保持/放下、一二站稳/起跳的专用动画。当前托举仍采用现有角色动画、托举支撑条和文字提示。本批没有增加新的技能、联机或发布部署。
