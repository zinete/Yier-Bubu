# 0.1 候选版 · 发布操作与真机验收

日期：2026-10-19。候选版本 `0.1.0-preview.1`；桌面和手机同步首发是目标，当前尚未批准公开发布。

## 一、本地复验与版本定位

```sh
pnpm install --frozen-lockfile
pnpm verify
pnpm preview --host 0.0.0.0
```

固定 pnpm 12.5.1、Node 22；依赖按锁文件安装。开发模式仍用 `pnpm dev`，生产验收使用 `preview` 或拟发布站点，不用开发热更新代表生产结果。

`dist/build-info.json` 包含版本、提交标识和构建时间；游戏设置/暂停菜单的“试玩反馈与版本”显示同一构建信息。本地存在未提交修改时标识带 `-dirty`，不能用该提交号声称能还原全部源码。

`pnpm check:dist` 检查版本一致、HTML 入口完整、相对路径和工坊独立 chunk。主 JS 1.4 MB、全部静态资源 23 MB 是临时回归上限，不是手机性能合格线；不等于首屏传输量。

## 二、反馈入口与隐私

- 主菜单 → 设置 → 试玩反馈与版本；或游戏暂停 → 试玩反馈与版本。
- 描述复现步骤 → 生成并复制报告 → 检查内容 → 手动发送给开发者。
- 自动复制失败时会选中报告，可手动复制。报告包含版本、浏览器、屏幕、当前角色/关卡及生命/时间，不收集存档、地图上传内容、网址或查询参数。
- 目前没有后台、在线反馈地址、错误自动上报或第三方统计；“复制成功”不代表开发者已收到。

| --- | --- | --- | --- |

### 每个目标平台的操作脚本

1. 新存档进入菜单，开始游戏；移动、跳跃、攻击完成三步引导。已有进度时显示继续游戏，从对应关卡起点进入。
2. 两角色分别通关 1-1、1-2；验证踩踏、侧撞扣血、1.1 秒无敌帧、弹体伤害、坠落复位、检查点、收集与最终结算。记录无法跨越、卡死或镜头遮挡的位置。
3. 分别触发死亡、倒计时失败；重复点击结算/暂停重玩，返回主页后再开始，检查只切换一次。
4. 暂停等待 10 秒，确认计时、移动和技能冻结；切后台、回前台、横转竖再转横，确认保持暂停且手动继续后无粘键。
5. 手机同时摇杆移动 + 跳跃 + 攻击；不同手指松开、滑出按钮后，其他操作不被误释放。先按住再旋屏/暂停/切后台，恢复后不持续移动或投掷。
6. 声音关闭/开启、音量调整、首次触摸解锁音频、后台不继续音乐；返回后不出现重复音乐。
7. 检查开始/设置/暂停/结算、反馈窗口在小屏上的文字、点击区和遮挡；打开软键盘后仍能关闭反馈。
8. 连续 20 分钟，至少重玩或切关 10 次。记录异常、帧率明显下降、发热、资源/内存持续增长；发现 P0/P1 问题先修复再复验。

### 生产网络/存储脚本

- 冷缓存正常网络启动，记录到达菜单和开始游玩的耗时；手机弱网（建议限制至 1 Mbps，下行 RTT 150 ms）重复记录，不预填“通过”。
- 阻断角色图集或主背景，确认停留加载页，恢复网络后点击重试，已成功资源不重复下载。
- 阻断声音资源/解码，确认仍能玩且不报致命异常。
- 阻断工坊 JS，确认工坊入口能提示失败，恢复后可重试；未进入工坊前不应请求工坊 JS/CSS。
- 禁用存储或模拟配额满，通关后应提示本次进度仅在内存；读取旧存档不能回滚新解锁。恢复存储并重试，刷新确认保存成功。
- 自定义地图仍是实验功能：也需单独检查导入失败、缺素材、超长地图与移动端编辑交互；未验收前不宣传为正式社区能力。

## 四、部署与回滚操作（未执行）

1. 先确认托管平台/域名、HTTPS 和素材使用权限；如需在线收集反馈，再单独确认接收渠道和隐私说明。当前不上传玩家数据。
2. 在干净的发布源码上运行 `pnpm verify`。GitHub 工作流会安装锁定依赖并保存 `dist` 产物，但当前只创建了配置，尚未推送或远端运行。
3. 将整个 `dist` 放入独立版本目录，例如 `releases/0.1.0-preview.1-<revision>/`；保留上一套完整产物。上传完后再切换站点入口，不只覆盖 JS 或 HTML。
4. `index.html`、`build-info.json` 使用重新验证/不缓存策略；哈希命名的 `assets/` 可长缓存。上线时核对内容类型、HTTPS、相对子路径、工坊延迟加载和资源 404；保留旧哈希资源供已打开页面使用。
5. 先向少量玩家开放，执行本页生产验收并记录实际构建号。未解决致命错误、资源授权不明或目标手机无法通关时不扩大发布。
6. 回滚时切回上一版完整目录，并使 HTML 缓存失效；不要清除玩家本地存档。当前存档仍是 v1，后续改格式应先验证旧版本读取和回滚兼容性。

以上是宿主无关流程，尚无真实部署地址、DNS 操作、自动发布或经过验证的生产回滚。

CI 配置参考官方 [checkout](https://github.com/actions/checkout)、[setup-node](https://github.com/actions/setup-node)、[pnpm action-setup](https://github.com/pnpm/action-setup)、[upload-artifact](https://github.com/actions/upload-artifact) 的使用说明。流水线仅有内容读取权限，不包含生产发布密钥。

## 六、小范围玩家验收（待执行）

在设备矩阵和网络检查通过后，先邀请 5–10 位玩家，至少覆盖两种手机系统；不要先大范围公开再补 P0。

每条问题记录：匿名测试编号、构建号、设备/浏览器、关卡、复现步骤、期望/实际、出现频率、截图或录屏、优先级、修复构建和复验结果。无需记录账号、手机号或完整地图上传内容。

发布阻断：启动黑屏/崩溃、主线无法完成、进度错误丢失、触控无法移动/跳跃、必要界面无法关闭。此类问题未修复复验不能扩大发布；其他问题记录已知限制。全部手工门槛通过并确认托管与授权后，才可把版本从“候选待验收”改为“公开试玩”。
