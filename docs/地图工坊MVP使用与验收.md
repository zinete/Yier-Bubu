# 地图工坊 MVP

入口：游戏主页主按钮下方的「地图工坊 · 创建自己的冒险」。建议在桌面或平板横屏中编辑。

## 创建与试玩

1. 初始地图含连续地面、出生点、检查点、终点和一颗星星。
2. 在左侧选择平台、星星、敌人等工具，可连续点击画布放置；按 Esc 或点击「选择 / 拖动」结束放置。出生点、检查点、终点为单例，放置会移动原标记。
3. 在「选择 / 拖动」模式点击对象查看属性，拖动修改位置。碰撞/操作框四边始终吸附 16px 网格，Shift 不再取消吸附；尺寸调整也按整格吸附。方向键移动一格，Shift+方向键移动四格。
4. 平台的宽高和类型在属性面板调整；敌人的速度、巡逻范围和远程攻击开关也在这里设置。修改后点击「应用对象属性」。
5. 修改标题、地图宽度、时间限制后点击「应用地图设置」。横向滚动可以编辑右侧区域。
6. 点击「试玩」。出生点/检查点下方需有平台、终点需连接平台。错误信息显示在底部。
7. 试玩时按 P 暂停，点击「返回编辑」或按 H；失败/胜利结算页也可返回工坊。自定义地图不影响官方进度。

## 保存与分享

- 「保存草稿」在当前浏览器保存一份草稿，刷新后重新进入工坊可恢复。试玩前和返回主页时也会保存。编辑过程中建议主动保存。
- 「导出地图」下载 `star-map.json`；把该文件分享给别人，对方点击「导入地图」后即可编辑与试玩。
- 导入限制为 3MB，版本 1；最多 200 个平台、300 颗星星、40 个敌人和 200 个自定义装饰，地图宽度至少 960px、不设固定上限，限时 30～600 秒。宽度必须为有限数值；超长地图仍受浏览器渲染和试玩性能影响，当前尚未实现分块加载。
- 新建与导入替换当前草稿，可撤销；无素材时历史保留最近 50 次编辑，含上传素材时保留最近 10 次，减少内存占用。刷新页面不保留撤销历史。
- 在选择模式点击对象（或 Alt 点击快速选择），按 Ctrl+C 复制、Ctrl+V 粘贴、Delete 删除；右侧也提供对应按钮。Ctrl+D 直接创建副本。粘贴自动选中新对象，并按网格逐次偏移，保留外观和属性。
- Ctrl+Z 撤销、Ctrl+Shift+Z / Ctrl+Y 重做；粘贴和删除均可撤销。出生点、检查点与终点为唯一标记，不可复制或删除。输入框、下拉框和富文本区域保留系统文字编辑快捷键。
- 对象复制使用工坊内部剪贴板，不读取或覆盖系统剪贴板。刷新/重新进入工坊、新建或导入地图会清空内部剪贴板；本轮支持单个对象，不包含多选和跨地图粘贴。

## 验证记录

- 浏览器已验证：进入工坊、放置平台、撤销/重做、保存草稿、刷新恢复、自定义地图试玩、暂停返回编辑，无未捕获异常。
- 自动测试覆盖：默认地图、JSON 往返、坐标与尺寸越界、不支持版本、对象上限、巡逻边界、终点/出生点不合法、未完成草稿与试玩校验差异。自定义 id 强制为 custom，不接受额外可执行字段。
- 文件选择/下载流程由浏览器处理；不同浏览器的下载行为及触屏拖动仍需验收。

## 当前边界

这是本地编辑器与文件分享 MVP，没有账号、在线发布或社区列表；也不读取 Tiled 文件。编辑画布使用 SVG 对象视图，支持背景实时预览，实际碰撞和玩法仍需进入试玩确认。

## 上传自定义素材

点击「上传图片」，选择不超过 2MB 的 PNG/JPEG/WebP。图片转换为 PNG，最长边不超过 512px；每张编码数据不超过 350KB，最多 20 张，总量不超过 2MB。选择素材后可连续放置，通过对象属性调整宽高，选择模式可拖动或删除实例。

上传素材默认以装饰方式显示，可通过「素材放置用途」改为平台、星星、敌人或检查点；已放置图片可在对象属性开启「作为可站立平台」。图片内嵌在草稿和导出文件中，导入地图后可直接显示。不要上传隐私图片，地图文件会携带素材内容。

## 场景设置

选择森林、雪地、沙漠或星空夜晚主题后，编辑画布立即更新天空、远景与中景，不再需要点击应用。编辑器与试玩共用主题背景图元和视差参数。平台图片材质独立设置，切换主题不会自动把苔藓素材替换成雪地素材。

上传素材后，可在「自定义背景」中选择图片。支持拉伸覆盖整个地图或按地图高度适配并横向平铺；仅使用主题背景时，图片铺设方式不可用。背景铺设按图片真实尺寸计算。视差 0 表示背景固定，1 表示与地图同步移动；主题和自定义背景都支持调整。横向滚动/空格拖动画布可立即查看效果，也可以点击「演示横向视差」移动视口。

设置修改立即进入当前地图，可以撤销/重做；点击「保存场景设置」或顶部「保存草稿」才写入浏览器存储。实时预览不会取消对象选择或移动对象；连续拖动视差滑块只计一次撤销。

选择装饰对象后，可在「显示图层」设置后景或前景，并应用对象属性。前景可能遮挡角色，请避免在主线路径放置大面积不透明图片。背景与装饰都不影响碰撞。

场景配置随草稿、导出和导入保存；未设置场景的旧地图默认森林。

结构校验无法证明整个关卡可通关；请作者实际试玩检查跳跃距离、平台高度和敌人分布。

## 模块化平台材质

默认苔藓平台已支持左右收边与中段重复，宽度变化不会把整张图片无限拉长。左侧「平台材质」可为默认或上传素材设置铺设方式、站立线、左右收边；设置随地图保存和分享。顶部「碰撞辅助线」默认关闭，开启可查看真正的站立面与碰撞范围，不会显示在试玩中。

完整使用方式、实现边界和验收清单见 [模块化平台材质与验收](./2026-10-15模块化平台材质与验收.md)。

### 跳台放置尺寸

新建跳跃平台默认 160×32。选择、移动、修改或缩放已有地面不会把地面宽度继承到跳台笔刷；复制/粘贴也只保留副本属性，不改变后续放置尺寸。明确修改跳台属性或拖动右下角改变尺寸后，才记住该跳台尺寸，便于连续放置；从跳台改成地面时恢复默认笔刷。

点击「恢复跳台尺寸 · 160×32」可随时恢复默认，只影响后续放置，不会缩短已有地面或跳台。新建、导入地图或重新进入工坊也会恢复默认笔刷尺寸。取消缩放不会覆盖此前笔刷尺寸。

## 碰撞边界吸附

放置预览、实际放置、拖动、缩放、复制、方向键移动及应用对象属性共用网格规则。星星和敌人的自定义关卡碰撞框为 32×32，图片保留原显示尺寸；平台、终点和图片装饰的宽高取整到 16px 的倍数。出生点、检查点和普通装饰没有物理碰撞，按操作框吸附。

旧地图不会在打开时批量改动；重新拖动、缩放或应用属性时，该对象会对齐网格。取消拖动或撤销可恢复原数据。地图边缘不足一整格的部分不会把对象挤到半格上。

详细验收见 [碰撞边界网格吸附](./2026-10-15碰撞边界网格吸附.md)。
